# CodeCrumbs

A self-contained Python practice website with a reward loop:

1. Answer a short Python question.
2. Unlock a 2–5 minute Cookie Catch snack break.
3. Return to the next teaching bite when the timer ends or when you end the break early.

## Run locally

From this folder:

```bash
uv run python -m http.server 4173
```

Then open `http://127.0.0.1:4173/`.

No build step or backend is required.
